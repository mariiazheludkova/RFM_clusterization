# Система кластеризації та сегментації товарів (RFM-аналіз)

Вебдодаток у вигляді інтерактивного дашборду для сегментації товарної бази на основі аналітичних показників **RFM (Recency, Frequency, Monetary)**. Проєкт розроблено для закриття конкретних аналітичних потреб бізнесу.

### 🛠 Стек технологій та методи:
* **Алгоритми машинного навчання:** KMeans, DBSCAN, Ієрархічна кластеризація (Hierarchical clustering).
* **Аналітика:** RFM-сегментація.
* **Інтерфейс:** Streamlit.

### 🔗 Демо додатка
Ви можете протестувати роботу системи наживо за посиланням:  
👉 [Запустити дашборд на Streamlit Cloud](https://rfmclusterization-dk4rvuiszxt4mfvilaevwb.streamlit.app/)

*Примітка: додаток оптимізовано для роботи з відомими датасетами UCI Online Retail (`online_retail_II 2009-2010.xlsx` та `online_retail_II 2010-2011.xlsx`).*
